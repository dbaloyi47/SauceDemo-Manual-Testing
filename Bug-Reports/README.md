# SauceDemo – Bug Reports

## Purpose

This folder contains defect reports identified during manual testing of the SauceDemo application.

## Bug Reporting Information

Each defect report should include:

- Bug ID
- Bug Title
- Application Module
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Evidence
- Defect Status

## Testing Approach

Defects will only be reported after reproducing unexpected application behaviour and collecting supporting evidence.

Hypothetical examples will not be presented as actual defects.
