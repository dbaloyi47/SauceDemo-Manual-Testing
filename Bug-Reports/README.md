# SauceDemo – Bug Reports

## Purpose
This folder documents defects identified during manual testing of the SauceDemo application.

## Testing Results

During the execution of the documented test cases, no confirmed defects were identified.

The application behaved as expected during the tests performed.

## Bug Reporting Information

If a defect is identified in future testing, the report will include:

- Bug ID
- Bug Title
- Application Module
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Evidence
- Defect Status

## Testing Approach

Defects are only reported after reproducing unexpected application behaviour and collecting supporting evidence.

Hypothetical examples are not presented as actual defects.

## Project Status

No confirmed defects identified during the executed test cases.
