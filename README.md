# SauceDemo Manual Testing Project

## 1. Project Overview

This project demonstrates practical manual software testing of the SauceDemo e-commerce application.

The objective was to evaluate the application's functionality, identify potential defects and document testing activities using standard software testing practices.

All 22 planned test cases were executed successfully, with a 100% pass rate.

## 2. Application Under Test

- Application: SauceDemo
- Website: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Testing Approach: Black-box Testing
- Testing Focus: Functional Testing

## 3. Testing Activities

The following testing activities were completed:

- Test planning
- Test scenario development
- Test case design
- Positive and negative testing
- Test execution
- Defect identification and reporting
- Test evidence collection
- Test summary reporting

## 4. Tools Used

- Microsoft Excel – Test case documentation and execution tracking
- GitHub – Project documentation and version control
- Google Chrome – Test execution

## 5. Project Deliverables

The project includes:

- Test Plan
- Test Cases (TC001–TC022)
- Bug Reports
- Test Execution Report
- Testing Evidence and Screenshots

## 7. Project Conclusion

Manual functional testing of the SauceDemo application was completed successfully.

All 22 test cases passed. The testing covered login functionality, product inventory, product sorting, shopping cart operations, checkout validation and order completion.

This project demonstrates practical knowledge of manual testing, black-box testing, test case design, test execution, evidence collection and test reporting.
