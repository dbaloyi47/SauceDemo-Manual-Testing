# SauceDemo – Test Execution

## Purpose

This folder contains the results of manual test execution performed on the SauceDemo application.

## Execution Activities

- Execute documented test cases.
- Compare actual results against expected results.
- Record Pass, Fail, Blocked or Not Run statuses.
- Capture screenshots as evidence.
- Report confirmed defects.

## Execution Summary

The execution summary will be updated after testing activities are completed.
