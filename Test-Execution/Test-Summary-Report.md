## Project 1: SauceDemo Manual Testing

**Testing Type:** Manual Software Testing  
**Test Environment:** Web Browser

### 1. Introduction
This report summarises the results of manual testing performed on the SauceDemo web application.

The purpose was to evaluate the application's functionality, identify unexpected behaviour and verify that its features operate according to their expected requirements.

### 2. Testing Objectives
- Verify user login and logout functionality.
- Test product display and sorting.
- Verify shopping cart functionality.
- Test navigation between application pages.
- Verify checkout functionality.
- Identify and document defects.

### 3. Scope of Testing
The following application areas were tested:

- Login and authentication
- Product catalogue
- Product sorting
- Navigation menu
- Shopping cart
- Checkout process
- Session access control

### 4. Testing Approach
Testing was performed manually by executing predefined test cases.

Each test case included:
- Test case ID
- Test steps
- Expected result
- Actual result
- Execution status
- Supporting screenshot evidence

### 5. Test Execution Results
A total of 23 test cases were prepared and executed.

Detailed execution statistics are recorded in the SauceDemo Test Execution spreadsheet.

### 6. Defect Summary
No unexpected defects were identified during the reported test execution.

### 7. Testing Limitations
Testing was limited to the functionality and scenarios covered by the prepared test cases. This exercise does not represent a full security, performance or cross-browser assessment.

### 8. Conclusion
The planned manual test execution has been completed.

The tested functionality behaved as expected in the scenarios reported as passed. No unexpected defects were identified during the testing exercise.

The project demonstrates practical experience in manual test execution, requirements verification, evidence collection, defect reporting and test documentation.
